Macros Draft

Last updated 2026-11-24 · Who: Agents run them; Admins build them

A macro is a saved list of steps. One click does them all, for example send a refund message, tag the ticket and resolve it.

Who can do this: Agents run macros. Only Admins add, change, delete or reorder them. Light agents cannot run them.

Run a macro

  1. Open the ticket and select Macros.
  2. Pick one. Each shows its steps, for example "Reply · Tag: refund · Status: resolved".

The steps run in order. If one is refused, nothing is saved, so a ticket is never left half changed.

Build one (Admins)

  1. Go to Settings › Service › Macros and select Add macro.
  2. Name it, then add steps. A step can be:
StepWhat it does
Send a replySends text to the customer. Placeholders are filled in. At most one.
Add a private noteAdds a note. At most one.
Set statusOpen, Pending or Resolved.
Set priorityUrgent, High, Medium or Low.
Set typeChanges the ticket type. It can apply only if the type is empty.
Move to teamChanges the team and re-routes the ticket.
Add tagAdds one tag.
  1. Save. New macros go last in the menu. Admins can reorder the menu.

Check it worked

The ticket shows every change, and the history has a line for each step.

Troubleshooting

What you seeWhyWhat to do
Macros does nothingYour role is Light agent, or a chat handover is not accepted.Use another role, or accept the chat.
Nothing changedA step was refused, so all were undone.Read the message and fix the cause, for example resolve open child tickets.
