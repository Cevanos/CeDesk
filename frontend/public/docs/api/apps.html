Install an app, or change its settings and credential (Settings)

PUT/api/v1/apps/{app}

The credential is checked with the provider first and then kept encrypted; only its last 4 characters are shown again. Audited.

Parameters

NameInTypeDescription
app requiredpathenum

Request body (JSON)

FieldTypeDescription
settingsobjectShopify: {"shop": "acme"}. Jira: {"site": "acme", "email": "ops@acme.com", "project": "SUP"}. Calendly: {"link": "https://calendly.com/acme/30min"}. Stripe and both Slack apps: none.
secretstring or nullThe app's credential (Slack alerts: the Incoming Webhook URL; Slack side conversations: the bot token, xoxb-...). Required, except for Calendly, which takes none.
signing_secretstring or nullSlack side conversations only: the Slack app's signing secret.
curl -X PUT "$CEDESK_URL/api/v1/apps/{app}" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'

Responses

200Successful ResponseAppOut
409Cevanos is connected: its integrations are used instead
422Bad settings, or the provider refused the credential
503The provider didn't answer; try again

The customer's latest orders (sidebar)

GET/api/v1/tickets/{ticket_id}/orders

Read live for the ticket's customer, at most 5; nothing is stored. With Cevanos connected, from the stores connected in Cevanos (source: cevanos; a store it couldn't read is named in message); else from the Shopify app, by email. Never fails because of the shop: see available.

The customer's latest payments (sidebar)
