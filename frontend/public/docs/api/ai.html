Improve the writing of a reply or note (Cevanos AI)

POST/api/v1/assist/improve

Returns the text rewritten in the tone, for the agent to edit and send; note says when nothing changed. Only when Cevanos is connected (GET /me ai); nothing is stored.

Request body (JSON)

FieldTypeDescription
text requiredstring
tonestring or nullOne of professional, friendly, empathetic, concise; default professional.
curl -X POST "$CEDESK_URL/api/v1/assist/improve" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "text": "string"
}'

Responses

CodeMeaningBody
200Successful ResponseImprovedOut
403An API key (AI help is for people), or the role can't
409cevanos_not_connected (connect Cevanos in Settings), cevanos_scope_missing (the key lacks a scope; the message names it) or cevanos_refused
503Cevanos is down or slow: try again
422Validation ErrorHTTPValidationError

Response fields (200)

FieldTypeDescription
textstring
notestring or nullShow it to the agent when set: "No changes suggested. Try another tone." (Cevanos sent the text back as it was; text is that text).

Translate a message or a reply (Cevanos AI)

POST/api/v1/assist/translate

Returns the text in to and the language it was in; note says when there was nothing to translate. Only when Cevanos is connected (GET /me ai); nothing is stored.

Request body (JSON)

FieldTypeDescription
text requiredstring
to requiredstringThe language to translate into, as a code: en, hi, pt-BR. A ticket's language (from triage) says what the customer writes in.
curl -X POST "$CEDESK_URL/api/v1/assist/translate" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "text": "string",
  "to": "string"
}'

Responses

CodeMeaningBody
200Successful ResponseTranslationOut
403An API key (AI help is for people), or the role can't
409cevanos_not_connected (connect Cevanos in Settings), cevanos_scope_missing (the key lacks a scope; the message names it) or cevanos_refused
503Cevanos is down or slow, or sent the text back untranslated ("Cevanos didn't translate this. Try again later.")
422Validation ErrorHTTPValidationError

Response fields (200)

FieldTypeDescription
textstring
fromstring or nullThe language found, e.g. hi.
notestring or nullShow it to the agent when set, instead of "Translated from …": "This is already in English." or "Cevanos found nothing to translate in this text." (text is the text as it was). A text Cevanos should have translated but sent back as it was is a 503 instead.

The AI card: handover rate, AI-resolved, CSAT of AI answers (Cevanos)

GET/api/v1/reports/ai

Read live from Cevanos for the period (default: the last 30 days), for the whole workspace. Needs reports. Only when Cevanos is connected (GET /me ai); nothing is stored.

Parameters

NameInTypeDescription
fromquerystring (date-time) or nullDefault: 30 days before to. With a time zone.
toquerystring (date-time) or nullDefault: now.
formatqueryenumcsv: the same report as a CSV file (md R7).

Example

curl "$CEDESK_URL/api/v1/reports/ai" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody
200Successful ResponseAiReportOut
403The role can't see reports (API keys can, like other reports)
409cevanos_not_connected (connect Cevanos in Settings), cevanos_scope_missing (the key lacks a scope; the message names it) or cevanos_refused
503Cevanos is down or slow: try again
422A bad period

Response fields (200)

Suggest a reply (Cevanos AI)

POST/api/v1/tickets/{ticket_id}/draft

A suggested reply for the reply box, written from the conversation (no internal notes) by the chat's Cevanos AI agent when the ticket came from a Cevanos chat. It is **never sent by itself**: the agent edits and sends it. Needs reply. Only when Cevanos is connected (GET /me ai); nothing is stored.
