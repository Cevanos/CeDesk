Email me a link to choose a new password

POST/api/v1/auth/forgot-password

Always 202, whether or not the workspace and email exist, so it can't be used to find accounts. The link lasts 30 minutes; at most 3 are sent per hour.

Request body (JSON)

FieldTypeDescription
workspace requiredstring
email requiredstring
curl -X POST "$CEDESK_URL/api/v1/auth/forgot-password" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "workspace": "string",
  "email": "string"
}'

Responses

CodeMeaningBody
202Successful Responseobject
429Too many attempts from this address; see Retry-After
422Validation ErrorHTTPValidationError

  "new_password": "string"
}'

Sign in with workspace address, email and password

POST/api/v1/auth/sign-in

Request body (JSON)

FieldTypeDescription
workspace requiredstring
email requiredstring
password requiredstring
curl -X POST "$CEDESK_URL/api/v1/auth/sign-in" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "workspace": "string",
  "email": "string",
  "password": "string"
}'

Responses

CodeMeaningBody
200Successful ResponseSignedInOut
401The details did not match (same answer for every reason)
403This address isn't on the workspace's IP list
429Too many attempts from this address; see Retry-After
422Validation ErrorHTTPValidationError

Response fields (200)

FieldTypeDescription
tokenstringSend as Authorization: Bearer <token>. Shown only once.
expires_atstring (date-time)
member_idstring (uuid)
roleenumOne of: admin, supervisor, agent, light_agent, custom
password_expiredbooleanTrue: show the change-password screen. Until the password is changed, every route except GET /me, POST /me/password and sign-out answers 403 PasswordExpired.
two_factor_requiredbooleanTrue: ask for the code from the authenticator app and send it to POST /auth/2fa with this token within 10 minutes. Until then every other route answers 403 TwoFactorRequired.

Change my password (ends my other sessions)

POST/api/v1/me/password

Request body (JSON)

FieldTypeDescription
current_password requiredstring
new_password requiredstring10 to 128 characters, not the current one.
curl -X POST "$CEDESK_URL/api/v1/me/password" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "current_password": "string",
  "new_password": "string"
}'

Responses

CodeMeaningBody
204Successful Response
403Locked after too many wrong passwords
409The password was changed elsewhere meanwhile
422Current password not right, or the new one is not allowed
429Too many attempts from this address; see Retry-After
