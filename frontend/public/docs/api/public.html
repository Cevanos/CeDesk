The open-tracking image in a campaign email (no sign-in)

GET/api/v1/public/open/{token}

Always a 1x1 transparent GIF, never an error. Counts the first open and every open (approximate: some mail apps load images for the reader).

Parameters

Example

  -H "Authorization: Bearer $CEDESK_KEY"

The unsubscribe page behind a campaign email's link (no sign-in)

The page reads the token from its link's #token=. Changes nothing (mail scanners open links): the page's button posts.

Unsubscribe from a workspace's campaigns (no sign-in; RFC 8058 one-click)

POST/api/v1/public/unsubscribe/{token}

The page's button, and the mail app's one-click unsubscribe (it posts List-Unsubscribe=One-Click as a form; any body is accepted). Always 200 with the same answer; doing it again changes nothing. Ticket replies still reach the person.

Send the web form: makes a ticket (no sign-in)

POST/api/v1/public/{workspace}/form

Channel web; rules, auto-assignment and SLA run as for any new ticket. Agent replies reach the customer by email. No ticket number comes back (anyone can post here).

Parameters

NameInTypeDescription
workspace requiredpathstring

Request body (JSON)

FieldTypeDescription
namestring
email requiredstring
message requiredstringIts first 60 characters become the subject.
type_idstring (uuid) or null
fieldsobject
websitestringHoneypot: render it hidden (off-screen, tabindex=-1, autocomplete="off") and always send it empty. Filled in: nothing is made.
curl -X POST "$CEDESK_URL/api/v1/public/{workspace}/form" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "string",
  "message": "string"
}'

Responses
