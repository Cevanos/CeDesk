Add a webhook (Admin; the secret is shown once)

POST/api/v1/webhooks

Each delivery is a POST with the JSON event as body and the headers X-CeDesk-Event, X-CeDesk-Delivery (the same on every retry), X-CeDesk-Timestamp (unix seconds) and X-CeDesk-Signature: sha256=<hex HMAC-SHA256(secret, '<timestamp>.<body>')>. Check the signature and that the timestamp is within 5 minutes. Answer 2xx within 10 s; otherwise it is tried again after 1 min, 5 min, 30 min, 2 h and 12 h. At most 20 per workspace (409). Audited.

Request body (JSON)

FieldTypeDescription
url requiredstringhttps, a public host name.
events requiredlist of enummessage.created: customer and agent replies only (never notes); it names the message, the text is read through the API.
enabledboolean
curl -X POST "$CEDESK_URL/api/v1/webhooks" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "url": "string",
  "events": [
    "ticket.created"
  ]
}'
