Connect a help desk to import from (Admin)

POST/api/v1/imports/connections

The credentials are checked with the source, then kept encrypted. 422 when the source refuses them, 503 when it can't be reached. Intercom, Zendesk, Freshdesk, Gorgias and Help Scout (HubSpot and Zoho Desk come in Phase 3). Accepts Idempotency-Key.

Parameters

NameInTypeDescription
Idempotency-Keyheaderstring or nullOptional, any unique string (a UUID is good), up to 255 characters. Send the same key when you retry: a repeat returns what the first request made (header Idempotent-Replayed: true) instead of making it twice. The same key with a different request is 422. Keys last 24 hours, per member.

Request body (JSON)

FieldTypeDescription

Upload a CSV file to import (Admin)

POST/api/v1/imports/csv

The request body is the file itself (UTF-8 CSV), not a form. One row per message, grouped by ticket_id. Required columns: ticket_id, subject, requester_email, message_from (customer, agent or note), message_body, message_created_at (ISO 8601). Optional: status, priority, channel, team, tags (; between), ticket_created_at, resolved_at, requester_name, assignee_email, csat_score, csat_comment, message_id, author_name, author_email, and field.<key> for custom fields. At most 25 MB (413). The file is deleted when the run ends. Rows that can't be read are listed as warnings and left out; they never stop the import. Accepts Idempotency-Key.

Resume a failed import where it stopped (Admin)

POST/api/v1/imports/runs/{run_id}/resume

The same run is queued again and the worker carries on from its last saved page: the page that failed is read again, the ones before it are not, and nothing is made twice. Counts, options, team mapping, the sync setting and the run's failures are kept; retry_attempts starts from 0. 409 when the run isn't failed (in progress, finished or syncing), when its connection was closed or its credentials can't be read (connect again and start a new import), or when another run of the connection is in progress or syncing. 404 for an unknown run. Two resumes at once queue it once. Accepts Idempotency-Key: a repeat returns the run the first one queued.
