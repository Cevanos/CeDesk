A short-lived link to download a file

GET/api/v1/attachments/{attachment_id}

Ask again for a new link once it expires (5 minutes by default). 409 when the file failed the virus scan, or (with scanning on) is still being checked.

Parameters

NameInTypeDescription
attachment_id requiredpathstring (uuid)

Example

curl "$CEDESK_URL/api/v1/attachments/{attachment_id}" \
  -H "Authorization: Bearer $CEDESK_KEY"

Attach a file to a ticket

POST/api/v1/tickets/{ticket_id}/attachments

The request body is the file itself (not a form), with its type in Content-Type, for example fetch(url, {method: 'POST', body: file, headers: {'Content-Type': file.type}}). At most 25 MB by default (CEDESK_ATTACHMENT_MAX_BYTES): 413 above.

Parameters

NameInTypeDescription
ticket_id requiredpathstring (uuid)
name requiredquerystringThe file's name, e.g. photo.jpg.
Idempotency-Keyheaderstring or nullOptional, any unique string (a UUID is good), up to 255 characters. Send the same key when you retry: a repeat returns what the first request made (header Idempotent-Replayed: true) instead of making it twice. The same key with a different request is 422. Keys last 24 hours, per member.

Request body

The file itself, not a form. See the description.
