Privacy

4 routes.

Erase one customer (Admin; can't be undone)

POST/api/v1/privacy/erase

Replaces the customer's name and address, every message, subject and field on their tickets, rating comments, task and approval texts and queued emails with (erased); deletes their files and exports from storage; signs them out of the portal; stops events not yet sent. Ticket counts, reply times, scores and time logged stay. 422 when confirm_email doesn't match; 409 when already erased. A chat kept in Cevanos must be erased in Cevanos too. Audited.

Request body (JSON)

FieldTypeDescription
contact_id requiredstring (uuid)
confirm_email requiredstringThe customer's email typed again. Erasing can't be undone.
curl -X POST "$CEDESK_URL/api/v1/privacy/erase" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "contact_id": "00000000-0000-0000-0000-000000000000",
  "confirm_email": "string"
}'

Export everything about one customer (Admin)

POST/api/v1/privacy/export

Makes a JSON file: the customer, every ticket with every message (internal notes too, marked note), file names and ratings. Download it with GET /privacy/requests/{id}/file within 7 days. Audited.

Request body (JSON)

FieldTypeDescription
contact_idstring (uuid) or null
emailstring or nullInstead of contact_id.
curl -X POST "$CEDESK_URL/api/v1/privacy/export" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
