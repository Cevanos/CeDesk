PUT/api/v1/portal-settings

Request body (JSON)

FieldTypeDescription

csat_surveybooleanEmail a 1-5 survey when a ticket is resolved.
web_formbooleanThe public contact form (/public/{workspace}/form) is open. Off: 404.

Open a ticket (customer)

POST/api/v1/portal/tickets

Rules, auto-assignment and SLA run as for any new ticket (channel portal). The subject is the first 60 characters of message.

Request body (JSON)

FieldTypeDescription
message requiredstringWhat happened. Its first 60 characters become the subject.
type_idstring (uuid) or nullFrom GET /portal/ticket-types.

Email me a sign-in code (customer)

POST/api/v1/portal/{workspace}/code

Always 202 for a valid email, whether or not we know it (and for an unknown workspace), so it can't be used to find customers. The code has 6 digits and works for 10 minutes; a new code replaces the last one; at most 5 per hour.

Parameters

NameInTypeDescription
workspace requiredpathstring

Request body (JSON)

FieldTypeDescription
email requiredstring
curl -X POST "$CEDESK_URL/api/v1/portal/{workspace}/code" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "string"
}'

Responses

CodeMeaningBody
202Successful Responseobject
403This portal is limited to some email domains (the message says which: show it)
422Not an email address
429Too many attempts from this address; see Retry-After
