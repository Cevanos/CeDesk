Live updates

4 routes.

Live updates for an agent (Server-Sent Events)

GET/api/v1/stream

Parameters

NameInTypeDescription
ticket requiredquerystring
last_event_idquerystring or null
Last-Event-IDheaderstring or null

Example

curl "$CEDESK_URL/api/v1/stream" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody
200An endless text/event-stream. Each event has an id (send it back as Last-Event-ID, or last_event_id, to carry on without losing one), an event kind and a JSON data of ids. reset: your last id is older than what is kept, refetch what you show. end: you were signed out. A line starting with : is a heartbeat. An id may repeat after a reconnect: ignore one you have seen.
401The ticket is unknown, used, expired, or its sign-in ended.
429You already have 5 live streams open.
422Validation ErrorHTTPValidationError

A one-use ticket to open the live stream

POST/api/v1/stream/ticket

Example

curl -X POST "$CEDESK_URL/api/v1/stream/ticket" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody
201Successful ResponseStreamTicketOut

Response fields (201)

FieldTypeDescription
ticketstringOpen the stream with this: GET /stream?ticket=....
