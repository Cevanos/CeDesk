Admin: business hours (days, hours, time zone) or 24/7

PUT/api/v1/sla/calendar

Hours are the same each working day, closing after opening (no overnight shifts). 422 for an unknown time zone.

Request body (JSON)

FieldTypeDescription

days requiredlist of integerISO: 1 Monday ... 7 Sunday.
opens requiredstring (time)
closes requiredstring (time)

  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \

  "timezone": "string",

Admin: save the ordered SLA policies (on/off, order, conditions, targets)

PUT/api/v1/sla/policies

Send the whole list. 422 when a name repeats, a target is out of range, the last policy has a condition or is off, or another policy matches every ticket.

Request body (JSON)

FieldTypeDescription
policies requiredlist of PolicyIn or nullThe whole list in order: the first enabled match wins. The last one must be on and have no conditions (Default). null: back to the three built-in policies.
curl -X PUT "$CEDESK_URL/api/v1/sla/policies" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "policies": [
    {
      "name": "string"

Admin: change the first-reply and resolve targets per priority

PUT/api/v1/sla/targets

Only the priorities sent change. The first reply can't be due after the resolution (422). Every open ticket's SLA is worked out again.

Request body (JSON)

FieldTypeDescription
targets requiredlist of TargetIn
targets.[]priority requiredenumOne of: urgent, high, medium, low
targets.[]first_reply_minutes requiredinteger
targets.[]resolve_minutes requiredinteger
curl -X PUT "$CEDESK_URL/api/v1/sla/targets" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "targets": [
