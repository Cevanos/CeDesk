Deploy the sandbox over the live settings

POST/api/v1/sandbox/deploy

All or nothing: every added, changed and removed rule, macro and saved reply is saved in one go, each with its own audit entry. The sandbox then holds a fresh copy of the live settings. Returns what changed. 422 when there is nothing to deploy or an item no longer fits (e.g. its team was deleted).

Example

curl -X POST "$CEDESK_URL/api/v1/sandbox/deploy" \
  -H "Authorization: Bearer $CEDESK_KEY"

Try the sandbox rules on sample tickets

POST/api/v1/sandbox/try

Runs the live rules and the sandbox rules on built-in sample new tickets (email refund, angry chat, web order question, phone invoice, portal thanks) and shows both results side by side. Nothing is saved.

Example

curl -X POST "$CEDESK_URL/api/v1/sandbox/try" \
  -H "Authorization: Bearer $CEDESK_KEY"
