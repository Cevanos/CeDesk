Save topic keywords and card redaction (Admin)

PUT/api/v1/triage-settings

New keywords apply from the next customer message; a ticket's topic is worked out again when its customer writes again.

Request body (JSON)

FieldTypeDescription
topics requiredlist of TopicIn or nullEach of the four topics once, with its keywords. null: back to the built-in lists. A ticket with none of the words is "General question".
redact_cardsbooleanRemove card numbers from customer messages before saving. Removed numbers can't be brought back.
curl -X PUT "$CEDESK_URL/api/v1/triage-settings" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "topics": [
    {
      "name": "string",
      "keywords": []
    }
  ]
}'
