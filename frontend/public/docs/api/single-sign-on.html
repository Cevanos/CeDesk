The identity provider's answer (ACS URL)

POST/api/v1/sso/{workspace}/acs

Redirects to <app_url>/sso/callback#token=...&expires_at=...&next=..., or #error=... when the answer is refused. The token is in the fragment, so it never reaches a server log.

Parameters

NameInTypeDescription
workspace requiredpathstring

Example

curl -X POST "$CEDESK_URL/api/v1/sso/{workspace}/acs" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody
303Successful Response
422Validation ErrorHTTPValidationError
