Set retention (Settings; audited)

PUT/api/v1/retention

The worker deletes once a day; each run is in the audit log (area retention). Deleted tickets can't be brought back.

Request body (JSON)

FieldTypeDescription
closed_ticket_days requiredinteger or null30 to 3650: delete resolved tickets (and their files) this many days after they were resolved; null keeps them for good. A cloud plan may cap it.
export_before_deleteboolean or nulltrue: before deleting, write the tickets to a JSON file an Admin can download for 30 days (GET /retention/exports). Left out or null: unchanged.
curl -X PUT "$CEDESK_URL/api/v1/retention" \
  -H "Authorization: Bearer $CEDESK_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "closed_ticket_days": 0
}'

Usage and plan limits (Settings)

GET/api/v1/usage

Over a limit, adding a member, uploading a file, or an agent or API key opening a ticket answers 402. A customer's own email, chat or portal request is never refused.

Example

curl "$CEDESK_URL/api/v1/usage" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody
200Successful ResponseUsageOut

Response fields (200)

FieldTypeDescription
planstring or nullThe cloud plan; null: no limits (self-hosted, or none set).
agentsintegerActive members who take tickets (light agents are free).
tickets_this_monthintegerMade this calendar month (UTC), not imported.
storage_bytesintegerFiles on tickets.
limitsobjectagents, tickets_month, storage_bytes; null: no limit.
retention_daysinteger or nullResolved tickets are deleted this many days after resolving; null: kept.

What retention wrote before deleting (Admin)

GET/api/v1/retention/exports

One file per batch of deleted tickets, newest first, with export before delete on. Kept 30 days. Admins only: they hold customer data.

Example

curl "$CEDESK_URL/api/v1/retention/exports" \
  -H "Authorization: Bearer $CEDESK_KEY"

Responses

CodeMeaningBody

Download a retention export (Admin; audited)

GET/api/v1/retention/exports/{export_id}/file
