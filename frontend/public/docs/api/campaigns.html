Download every recipient's result as CSV (Admin; audited)

GET/api/v1/campaigns/{campaign_id}/recipients/export

email, name, status, queued_at, sent_at, bounced_at, first_opened_at, open_count, unsubscribed_at, complained_at, error. UTF-8 with a byte order mark; a value a spreadsheet would run as a formula starts with '.

curl "$CEDESK_URL/api/v1/campaigns/{campaign_id}/recipients/export" \
