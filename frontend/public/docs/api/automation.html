POST/api/v1/flows

Request body (JSON)

FieldTypeDescription
name requiredstring
graph requiredobjectThe builder's graph: {"nodes": [...], "edges": [...]}. Node types: trigger ({"id", "type": "trigger", "event"}), condition ({"conditions": [...]}, leaves by yes or no), action ({"action": {...}}, one rule action), wait ({"minutes": 1-43200, "until": "customer_replied"?}: next; with until: replied or timeout). Edges: {"from", "to", "when"}. One trigger, every node reachable, at most one edge per way out, no loop without a wait, at most 50 nodes and 100 edges. A node may carry position and label for the canvas. GET /automation/catalog lists every kind with its parameters.
enabledbooleanWorkflows start turned off.
max_runs_per_hourintegerAt most this many runs in any hour, all tickets together (blocked runs are logged, not counted). Default 1000.
max_runs_per_dayintegerAt most this many runs in any 24 hours. Default 10000; not below the hourly limit.

POST/api/v1/flows/{flow_id}/versions/{version}/restore

History is never rewritten: the older graph becomes the next version. Runs waiting on a wait step carry on with the version they started on. 404 for a version the workflow never had; 409 when it is the current graph already.
