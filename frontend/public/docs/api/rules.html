Add a rule; it runs after the others (Admin)

POST/api/v1/rules

Request body (JSON)

FieldTypeDescription
name requiredstring
enabledboolean
event requiredenumcreated: a new ticket. customer_replied: the customer wrote on an Open or Pending ticket. sla_breached: an open ticket's SLA clock ran out (checked once a minute; once per clock). snooze_ended: a snoozed ticket's time came and the worker reopened it. Agent edits never run rules. One of: created, customer_replied, sla_breached, snooze_ended
conditions requiredlist of objectAll must match. Each is one of: {"kind": "text_contains_any", "words": ["refund"]} (subject and customer messages, any case); {"kind": "channel_in", "channels": ["email"]}; {"kind": "to_address_contains", "text": "billing@"}; {"kind": "status_in", "statuses": ["pending"]}; {"kind": "sentiment_in", "sentiments": ["negative"]}; {"kind": "sla_in", "states": ["breached"]} (the SLA pill's clock: on_track, close, breached, met; not on created); {"kind": "contact_field", "key": "plan", "op": "equals", "value": "gold"} (op: equals, not_equals, is_set, not_set, contains, more_than, less_than); {"kind": "contact_vip", "value": true}; {"kind": "contact_in_segment", "segment_ids": ["..."], "negate": false}; {"kind": "time_since", "of": "customer_reply", "op": "more_than", "minutes": 2880} (of: customer_reply or agent_reply); {"kind": "snoozed", "value": true}; {"kind": "has_followers", "value": true}. GET /automation/catalog has each one's parameters.
actions requiredlist of objectRun in order. Each is one of: {"kind": "set_type", "type_id": "...", "only_if_empty": false}; {"kind": "set_team", "team_id": "..."}; {"kind": "set_priority", "priority": "high", "keep_urgent": true}; {"kind": "set_status", "status": "open"}; {"kind": "add_tag", "tag": "upset"}; {"kind": "snooze", "minutes": 1440}; {"kind": "add_follower", "member_id": "..."}; {"kind": "send_email", "body": "Hi {{customer.first_name}}, ..."}; {"kind": "call_webhook", "webhook_id": "..."} (Admins only).
max_runs_per_hourintegerAt most this many runs in any hour, all tickets together (blocked runs are logged, not counted). Default 1000.
max_runs_per_dayintegerAt most this many runs in any 24 hours. Default 10000; not below the hourly limit.
