Rules Draft

Last updated 2026-11-24 · Who: Admins

A rule says: when this happens, and the ticket matches these conditions, do these actions. For steps that need to wait, use Workflows.

Who can do this: Admins.

See your rules

Go to Settings › Service › Rules. Each rule shows its name, whether it is on, and a line such as "When a ticket is created · Subject or customer message contains: refund → Set ticket type, Set team, Set priority: High".

Add a rule

  1. Select Add rule and name it.
  2. Choose when it runs:
WhenRuns
A ticket is createdFor every new ticket.
The customer repliesWhen the customer writes on an Open or Pending ticket.
Its SLA is breachedWhen an open ticket's response-time clock runs out. Checked once a minute, once per clock.
A snooze endsWhen a snoozed ticket wakes up.
  1. Add conditions. All must match.
ConditionChecks
Subject or customer message containsAny of the words you list, any case.
Channel isEmail, chat, web and so on.
Sent to an address containingPart of the support address the customer wrote to.
Status isOpen, Pending or Resolved.
Sentiment isNegative, neutral or positive.
SLA state isOn track, close, breached or met.
Contact fieldA customer's field equals, contains, is more or less than a value, or is set.
Customer is VIPYes or no.
Customer is in a segmentOr is not.
Time sinceMore than a number of minutes since the customer's or an agent's last reply.
Snoozed, Has followersYes or no.
  1. Add actions. They run in order.
ActionDoes
Set ticket typeChanges the type, optionally only if empty.
Set teamChanges the team, which re-routes the ticket.
Set priorityChanges the priority, optionally keeping Urgent.
Set statusOpen, Pending or Resolved.
Add tagAdds a tag.
SnoozeFor a number of minutes.
Add followerAdds a member as follower.
Send emailReplies to the customer. Placeholders such as {{customer.first_name}} work.
Call a webhookSends the event to a webhook.
  1. Save.

Order, on and off, and delete

Rules run top to bottom, and the order matters: use the up and down arrows next to a rule. The Enabled switch turns a rule on or off. Delete removes it.

A rule that points at something deleted, such as a team, shows a problem you need to fix.

Check it worked

Make a test ticket that matches. Its history shows "Rule applied: …".

Troubleshooting

What you seeWhyWhat to do
The rule did not applyAgent edits never run rules, or a condition did not match.Use Test on a ticket.
A problem is shown on the ruleA team, type or webhook it uses was deleted.Edit the rule and choose another.
Two rules fightThey run in order, and the later one wins.Reorder them.
