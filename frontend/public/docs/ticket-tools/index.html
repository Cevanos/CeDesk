Ticket tools

Tasks, time, approvals, side conversations, Jira, ticket types and the archive.

  1. Tasks on a ticket — Add a to-do to a ticket, give it an owner and a due time, and mark it done.
  2. Log time on a ticket — Record how long you spent, mark it billable, and see the totals.
  3. Ask for and give approval — Ask a Supervisor or Admin to approve something, such as a refund, and decide requests waiting for you.
  4. Side conversations — Ask someone outside the ticket, by email or in a Slack channel, without the customer seeing it.
  5. Jira issues on a ticket — Create a Jira issue from a ticket, or link an existing one.
  6. Ticket types and their fields — Define the kinds of requests you handle and the extra fields each one asks for.
  7. Find archived tickets — Where old resolved tickets go, how to read them, and how to change when they move.
