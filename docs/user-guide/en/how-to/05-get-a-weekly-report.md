> **Who can do this:** Supervisors and Admins.

1. Open **Reports › Scheduled reports** and select **New schedule**.
2. Name it, such as "Weekly volume", and choose a ready-made report, for example tickets created per day.
3. Set the period to the last 7 days.
4. Choose weekly, pick Monday, and choose the hour.
5. Add the people who should get it. Each must be able to see reports.
6. Save.

**Check it worked:** **Next run** shows next Monday, and **Last sent** fills in after the first email.

More: [Scheduled reports](../reports/scheduled-reports.md), [Build and save a report](../reports/build-and-save-a-report.md).
