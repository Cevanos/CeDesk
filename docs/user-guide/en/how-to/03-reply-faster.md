> **Who can do this:** Agents use these. Admins create saved replies and macros.

1. Ask an Admin to add your common answers under **Settings › Service › Saved replies**, each with a short name such as `refund`.
2. In a reply, type `/` and the name, then pick the reply. Add a line for this customer. Select **Send reply**.
3. For jobs with several steps, such as reply, tag and resolve, ask an Admin to build a macro under **Settings › Service › Macros**. Then select **Macros** on the ticket.
4. On **Tickets**, set the filters you use daily and select **Save view**, so one click shows your work.

**Check it worked:** a common reply takes a few clicks and the ticket's history shows each step.

More: [Saved replies](../working-with-tickets/saved-replies.md), [Macros](../working-with-tickets/macros.md), [Save a view](../working-with-tickets/save-a-view.md).
