# Security policy

## Report a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on the repository's **Security** tab choose
**Report a vulnerability**. Include what is affected, how to reproduce it and the impact
you see. We aim to reply within 3 working days and will keep you updated until it is fixed.

How the web app protects sessions, cookies and requests:
[frontend/SECURITY.md](frontend/SECURITY.md).

## Supported versions

Security fixes go into the latest release and `main`. Please update to the latest
version before reporting.
